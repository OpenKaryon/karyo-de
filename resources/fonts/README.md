# IBM Plex runtime assets

Unmodified complete IBM Plex Sans and IBM Plex Mono TTFs from IBM/plex revision
71f558992315a12ca1f06a2215d57962a1992162, originally reviewed in the prototype.
Upstream directories: packages/plex-sans/fonts/complete/ttf and
packages/plex-mono/fonts/complete/ttf. SHA256SUMS records the original payloads.
Regular, Italic, Medium, MediumItalic, SemiBold, SemiBoldItalic, Bold and BoldItalic
include Latin and Cyrillic. Copyright IBM Corp., Reserved Font Name Plex.

These font files remain under SIL OFL 1.1, not the code's GPL. Both upstream
copyright/license notices are preserved alongside the fonts and in the runtime
package. The package supplies font files only. Karyo already requests these
families explicitly; no global sans-serif/monospace or other desktop aliases
are overridden. Noto fallback and color emoji come from distribution packages.
